# Food Delivery Web Application

A modern food delivery web application built with React and Tailwind CSS. This application provides a seamless experience for users to browse restaurants, view menus, and place food orders.

## Features

- 🎨 Modern and responsive UI with dark/light mode
- 🗺️ Interactive map for address management
- 🛒 Shopping cart functionality
- 🔍 Search and filter options
- 📱 Mobile-first design
- 🌙 Dark/Light theme support

## Tech Stack

- React
- Tailwind CSS
- Mapbox GL JS
- React Router
- Heroicons

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/food-delivery.git
cd food-delivery
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root directory and add your Mapbox access token:
```
VITE_MAPBOX_ACCESS_TOKEN=your_mapbox_token_here
```

4. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`
